# Amazon Clone - Requirements Document

## 1. Project Overview

Amazon Clone is a full-stack e-commerce web application that allows users to browse products, search for items, add products to a shopping cart, place orders, and manage their accounts.

The objective of this project is to learn and demonstrate full-stack web development using Java, Spring Boot, MySQL, HTML, CSS, JavaScript, REST APIs, and modern software engineering practices.

---

## 2. Project Goals

- Learn frontend development.
- Learn backend development.
- Learn REST APIs.
- Learn database design.
- Learn authentication and authorization.
- Learn deployment.
- Build a resume-worthy project.
