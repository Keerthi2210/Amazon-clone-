# Amazon Clone - User Flow

## Customer Flow

1. User opens the website.
2. User browses products.
3. User searches or filters products.
4. User opens a product page.
5. User adds a product to the cart.
6. User views the cart.
7. User proceeds to checkout.
8. User logs in (if not already logged in).
9. User selects or adds a shipping address.
10. User reviews the order summary.
11. User places the order.
12. Order confirmation is displayed.
13. User can view the order in Order History.

---

## Admin Flow

1. Admin logs in.
2. Admin opens the dashboard.
3. Admin manages products.
4. Admin manages categories.
5. Admin views customer orders.
6. Admin updates order status.
